## Cập nhật Windows hiện có

Dừng API và worker đang chạy bằng Ctrl+C hoặc dừng đúng scheduled task của Super Net. Sao lưu DB + DATA_DIR bằng script hiện có trước migration; giữ nguyên `.env` và VAULT_KEY. Không chạy seed demo trên dữ liệu đang dùng.

```powershell
cd D:\AI\task
node .\scripts\backup.mjs D:\SuperNetBackups
git pull --ff-only
npm ci
npm run build
npm run migrate
npm start
```

Cửa sổ PowerShell thứ hai: `npm run worker`. Giữ cửa sổ API mở. `.env` dùng `HOST=0.0.0.0`, `PORT=3002`; mở `http://localhost:3002`, Ctrl+F5. Máy công ty khác dùng `http://<IP-LAN-máy-chủ>:3002` theo [hướng dẫn firewall](WINDOWS.md). Kiểm thử cloud HTTP LAN là mô phỏng context trình duyệt, chưa thay cho thử hai máy Windows thật.

Migration 005 tạo registry/version/mapping, comments, updates và tệp staging. Dữ liệu task trước registry giữ ID/status/version/payload/thời gian; snapshot giữ hợp đồng mẫu trước đây. Những mã trước đây dùng OTHER được đánh dấu hợp đồng lịch sử rõ ràng, không chuyển sang schema mới khi migration. Báo cáo đã nộp không bị ghi lại. Không cần bootstrap lại, không đổi mật khẩu/tài khoản. Nếu đã tách runtime role và migration role, kiểm tra quyền runtime trên các bảng/sequence mới theo SCHEMA.md.
